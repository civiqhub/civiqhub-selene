# Glossary

Checked against the code of `develop` at commit `97a0f15`.

## In plain words

The engine uses one word for each thing, the same in the code, the reference of the API and this section. This page lists the words of the mathematical model, what each means, the symbol of [Notation](notation.md) that stands for it, and its name in the code. It agrees with the words of [Architecture](../architecture.md#words).

## Words without an entry

The words split, dissensus and regime of the ordinal family name quantities that are defined in the design notes of the engine and not implemented: no name of the code holds them, and they have no entry here.
